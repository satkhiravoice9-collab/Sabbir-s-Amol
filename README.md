# Sabbir's Amol (সাব্বির'স আমল) 📱🤲

**Sabbir's Amol** হলো একটি আধুনিক অ্যান্ড্রয়েড অ্যাপ্লিকেশন, যা দৈনন্দিন ইসলামিক আমল, নামাজ ট্র্যাকিং, ২৬টি গুরুত্বপূর্ণ ছোট সূরা ও জিকির সহজে বজায় রাখতে সাহায্য করে।

---

## 🌟 মূল ফিচারসমূহ (Key Features)

* **দৈনিক আমল চেকলিস্ট:** ৫ ওয়াক্ত সালাত, নফল নামাজ ও সকাল-সন্ধ্যার আজকার ট্র্যাকার।
* **২৬টি ছোট সূরা ও আমল:** আরবি টেক্সট, বাংলা উচ্চারণ ও অর্থসহ প্রয়োজনীয় সূরা ও দোয়া।
* **অগ্রগতি ট্র্যাকিং:** প্রতিদিনের আমলের অগ্রগতি দেখতে ইন্টারঅ্যাক্টিভ প্রগ্রেস বার।
* **ডিজিটাল তাসবীহ:** দ্রুত ও সহজে জিকির গণনার সুবিধা।
* **অফলাইন সাপোর্ট:** ইন্টারনেট ছাড়াই সব ফিচার ব্যবহারযোগ্য।

---

## 🛠 টেকনোলজি স্ট্যাক (Tech Stack)

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Local Database:** Room Database
* **CI/CD:** GitHub Actions (Automated Build & APK Generation)
